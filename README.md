# 구글 문서 알림 (Google Doc Notifier)

지정한 구글 문서(예: 2학년부 업무 일지)의 변경 사항을 주기적으로 확인해서,
바뀐 내용이 생기면 화면에 알림 창으로 보여주는 윈도우용 트레이 프로그램입니다.

- 10분마다 문서를 확인하고, 변경이 감지되면 3분 뒤 한 번 더 확인해서 확정되면 알려줍니다.
- 날짜 구역별로 추가/삭제/수정 내용을 색으로 구분해서 보여줍니다.
- 윈도우 시작 시 자동 실행되고, 작업 표시줄 트레이 아이콘에서 지금 검사 / 문서 열기 / 로그 보기를 할 수 있습니다.
- **이미 설치된 프로그램이 자동으로 새 버전을 내려받아 스스로 업데이트합니다.**
  (교사들에게 exe 파일을 다시 나눠줄 필요가 없습니다.)

## 자동 업데이트는 어떻게 동작하나요?

프로그램이 실행되는 동안 3시간마다 이 GitHub 저장소의
[Releases](https://github.com/HanahKim37/google_doc_notifier/releases)에서
최신 버전을 확인합니다. 더 높은 버전이 올라와 있으면:

1. 릴리스에 첨부된 `google_doc_notifier.exe`를 자동으로 내려받고
2. 잠깐 트레이 알림을 띄운 뒤
3. 실행 중인 프로그램을 종료하고 새 exe로 교체한 다음
4. 자동으로 다시 실행합니다.

교사들 컴퓨터에서는 아무것도 할 필요가 없습니다. (인터넷 연결만 되어 있으면 됩니다.)

> 저장 위치(`doc_state.json`, `doc_change_log.txt`)는 내 문서 폴더가 아니라 사용자 홈 폴더에
> 저장되므로, 업데이트해도 그동안의 감시 상태와 로그는 그대로 유지됩니다.

## 새 버전을 배포하는 방법 (관리자용)

새 버전을 만들어서 이미 깔려있는 프로그램들이 자동으로 받아가게 하려면:

1. `google_doc_notifier.py` 맨 위쪽의 `CURRENT_VERSION`을 올립니다.
   예: `"1.0.0"` → `"1.0.1"`
2. `build.bat`을 더블클릭해서 `dist\google_doc_notifier.exe`를 새로 만듭니다.
3. 코드 변경을 GitHub에 올립니다 (아래 "코드 올리기" 참고).
4. GitHub 저장소 페이지 → **Releases** → **Draft a new release**
   - **Tag**: 방금 올린 버전과 똑같이, 앞에 `v`를 붙여서 입력 (예: `v1.0.1`)
   - **Release title**: 자유롭게 (예: `v1.0.1`)
   - 아래 **Attach binaries** 영역에 `dist\google_doc_notifier.exe` 파일을 그대로 끌어다 놓기
     - ⚠️ 파일 이름은 반드시 **`google_doc_notifier.exe`** 그대로여야 합니다. 이름을 바꾸면 자동 업데이트가 새 버전을 찾지 못합니다.
   - **Publish release** 클릭

이렇게 릴리스를 올리고 나면, 이미 선생님들 컴퓨터에서 실행 중인 프로그램들이
길어도 3시간 안에 (또는 트레이 메뉴 → "업데이트 확인" 클릭 시 즉시) 자동으로
새 버전을 받아서 스스로 교체·재시작합니다.

## 코드 올리기 (최초 1회 / 이후 수정 시)

```
git add -A
git commit -m "설명"
git push
```

## 처음 설치하는 선생님에게 드릴 때

`dist\google_doc_notifier.exe` 파일 하나만 전달하면 됩니다. 실행하면:

- 윈도우 시작 시 자동 실행되도록 등록되고
- 트레이(작업 표시줄 오른쪽 숨김 아이콘 `^`)에 파란 문서 아이콘이 생깁니다.

이후 업데이트는 이 문서 위쪽의 "자동 업데이트" 설명대로 자동으로 처리됩니다.
